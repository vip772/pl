# 音乐刷新与运行日志优化

本轮在现有聊天功能与启动调度之外减少重复工作，未改动 DexKit 并发、聊天顶部/底部避让或发送按钮收尾。

- 悬浮歌词：只缓存当前歌词内容，内容变化时解析并稳定排序。250ms 刷新只做二分查找；同时间戳取最后一项、多时间标签、向前/向后拖动、无歌词提示保持原有语义。异常超大时间标签跳过；文字相同时不再 setText。
- 二级播放器：时间文字与进度条合并至一个500ms任务，共用 duration/currentPosition 采样；秒数不变不重新格式化和更新文字，进度不变不重复设置。保留原有暂停刷新节奏、拖动保护和 detach 清理，未引入额外播放状态监听。
- Canvas：复用封面裁剪Path、源Rect、目标RectF、进度轨道RectF、触摸区域对象；频谱渐变仅边界变化时重建。装饰背景已有缓存，未重构绘制风格与帧率。
- 群昵称回退：只对相同群、相同成员/名称数量的重复DEBUG提示去重，上限256项；状态变化时重新记录，映射恢复正常时清除对应去重状态。联系人查询、昵称回退与数据均不缓存或改写。
- 运行日志：保留异步单写线程与1024条待处理上限，后台每批最多64条合并追加；无固定等待窗口。保留日志时间、堆栈、溢出提示、轮转、关闭、导出屏障及清空行为。WARN/ERROR的LSPosed输出不变。

验证：音乐绘制Android SDK定向编译与视觉契约、收藏导航；歌词多时间标签/同时间戳/前后拖动/替换/空歌词；生产进度绑定的拖动、准备中跳过与解绑；800条并发日志、顺序/关闭/导出/清空/错误文本；Java日志去重与容量边界。均为定向编译和桩验证，不代表完整APK构建或实机性能数据。未运行Gradle、未构建APK，未量化性能收益。

保留此前未提交的分组恢复与快捷已读日志修复，本轮不提交、不推送。
