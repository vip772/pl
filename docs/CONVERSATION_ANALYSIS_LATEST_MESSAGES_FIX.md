## 重复 null 的源码原因与修订
原 JSON 和 SSE 路径直接 optString(content)，JSON null 可能转换成字符串 null 并累计。两条路径现只接受 String；缺失、JSONObject.NULL、数字、对象及非正文元信息均不追加。正文中真实的单词 null 保留。未获得故障时真实接口响应，因此确认的是可复现的源码缺陷，不宣称它是服务端全部异常的唯一原因。
