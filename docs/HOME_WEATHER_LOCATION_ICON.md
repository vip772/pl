# 首页天气定位图标

城市名称左侧的定位符号由字体字符 `⌖` 改为 Canvas Path 绘制的空心地图定位针，内含小圆环。图标尺寸16×18dp、文字间距5dp，通过TextView相对复合Drawable垂直居中，标准与紧凑卡片共用。颜色取城市文字的currentTextColor，不另设独立配色；卡片文字当前固定配色，本次未调整整张卡片的深色模式策略。

Drawable不加载图片、不运行动画，Path与Paint只创建一次，绘制时随bounds缩放。城市与更新时间布局、天气查询和交互保持原流程。

已通过Android SDK加依赖桩的天气模块定向编译和git差异检查；未执行Gradle完整构建或微信实机视觉验收。
