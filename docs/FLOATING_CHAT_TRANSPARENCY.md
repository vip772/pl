# 悬浮聊天背景透明度

悬浮标题栏和悬浮输入框设置页分别增加背景透明度，复用现有悬浮底栏Miuix Slider的百分比、0–100范围、99步和松手保存样式。功能关闭时隐藏滑块。0%为不透明，100%为全透明；只调整卡片填充和描边，文字、头像、操作图标、输入文字及发送按钮不使用View.alpha淡化。

配置位于现有Hchat_global_config，独立键为floating_chat_header_transparency、floating_chat_footer_transparency，纳入原配置文件备份路径。运行时缺失键使用-1保留原有外观，不在打开设置时写入默认值；滑块未配置时显示近似现有胶囊/输入框的10%。用户选择并松手后才明确应用百分比；标题栏兼容卡片原本全不透明，不保证未配置时与滑块默认显示完全对应。

标题栏覆盖返回/标题/更多胶囊及原有标题卡片背景；输入框覆盖两处原有卡片应用入口。沿用现有配置监听，变化后在主线程缓存数值并触发现有刷新；背景Drawable复用，只在颜色变化时设置。没有新增Hook、滚动监听、定时任务、数据库访问或逐帧布局操作。原有消息顶部/底部避让、输入模式动画和点击区域保持。

验证：生产卡片与透明度辅助类Android SDK定向编译通过，端点、50%、10%、范围约束、RGB保留和缺失键兼容通过；原顶部避让、底部实际重叠补偿和输入模式切换回归通过。未运行Gradle、未完整编译Compose页面、未构建APK或实机A/B，实际透明度与切换效果待新包验收。本轮不提交、不推送，保留此前艾特提醒及工具栏图标修改。
