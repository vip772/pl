# 首页扩展按需刷新优化

## 联系人卡片

会话变更仅在首页扩展开启、最近联系人开启且非固定收藏模式时合并触发600ms刷新。查询仍走原后台执行器；卡片未挂载、不可见或失焦时只保留失效状态，重新可见时再检查。固定收藏仍保留原30秒缓存有效期，在重新可见/原有刷新入口中检查，避免联系人名称和头像长期固定。

新增首页根View的滚动可见性观察，仅检查联系人卡片是否从不可见进入可见，不扫描控件树或消息列表；detach/dispose时移除。隐藏期间返回的查询结果只更新数据缓存，界面更新延后至可见。头像下载和延迟失败重试增加可见性门控；已开始的下载不强制中断，结果仍通过原有代次校验。

## 卡片复用

保留现有整体布局组装以维护原生列表头、双列和顺序；按卡片配置签名复用未变化的日历、联系人、天气和音乐View，避免重复创建内容。单/双列、深色模式、日历跨日、天气时间桶及对应卡片配置变化会失效。照片保留原资源/版本/宽高/透明度复用。配置快照在一次render中读取一次。关闭卡片时移除缓存；日历异步背景回调校验当前缓存卡片身份与资源版本。

此实现减少内容构建，不代表完全消除removeAllViews、布局及attach/detach。

## 静态照片

共享SidePanelMediaView暴露解码中或动态媒体状态。解码结束确认为静态图时，首页扩展移除播放可见性的滚动观察，焦点与布局回调快速返回；GIF/动画WebP/视频保持原有播放和有限恢复机制。释放媒体时清除回调。未修改图片拖动、缩放或播放帧率。

## 验证及限制

通过test_home_extension_idle.py：执行生产可见性门控和卡片签名，验证隐藏/失焦/加载中不查询、有效缓存不重复查询、天气配置不使日历/音乐失效、双列和主题变化失效。

通过首页列表复用隔离、日历背景Android SDK定向编译、天气解析/六小时缓存及媒体播放/关闭解码竞态回归，git diff --check通过。未进行完整HomeExtensionRuntime Android编译、未运行Gradle、未构建APK或新包实机性能测试；需实机验收返回首页补刷、卡片滚出滚入、布局切换及GIF/视频启停。
