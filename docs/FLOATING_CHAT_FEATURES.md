# 悬浮标题栏

入口位于美化设置，运行实现为 `FloatingChatHeaderFeature`，通过 `BaseFeature` 和 `DexInstallScheduler` 接入微信聊天布局生命周期。仅处理当前可见聊天布局，保留原生返回、标题和更多按钮的点击转发。

标题栏支持卡片与三段胶囊展示，头像、昵称及公告提示沿用现有绑定和恢复流程。顶部留位由标题栏独立维护，关闭或销毁时恢复原布局、背景及监听器。

`FloatingChatCardVisuals` 管理标题卡片的圆角、深浅色表面和透明度；`FloatingChatActionBarBackgrounds` 管理原生 ActionBar 的独立背景层。沉浸式背景继续避让标题栏拥有的表面，防止背景回写覆盖标题展示。

布局刷新沿用现有调度与缓存，不新增滚动扫描、定时轮询或数据库查询。沉浸式背景的原生输入栏透明和消息透底由 `ChatInputMessageUnderlay` 独立维护，详见 [原生输入栏透底](CHAT_INPUT_MESSAGE_UNDERLAY.md)。

## 2026-10-29 功能移除

已移除悬浮输入框的运行实现、注册、设置页、底部避让与发送按钮补偿、专属诊断和测试。沉浸式背景不再读取该功能的开关，原生输入栏及面板沿用微信层级。旧配置只在备份边界识别并忽略：新导出排除旧配置，导入旧备份不恢复旧配置，标题栏及其他功能配置继续正常处理。

## 验证范围

标题栏、胶囊、ActionBar 背景管理、卡片及透明度代码通过真实 Android 36 SDK 定向编译，项目辅助 API 使用桩。顶部留位、原生输入栏透底、背景布局所有权和首页点击反馈另有源码回归检查。检查不等同于完整工程构建或真机交互、帧率验收，未扩展既有微信版本兼容范围。
