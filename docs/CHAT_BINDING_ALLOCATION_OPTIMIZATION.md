# 聊天绑定与绘制分配优化

本轮选择不改变数据新鲜度和绑定时序的部分：消息文字颜色、气泡匹配、群头衔及实名尾字的固定Regex移为文件级实例；自定义聊天时间复用受同步保护的SimpleDateFormat和Date，格式、Locale、时区ID或规则变化时重新构造，非法格式保留原默认格式回退；昵称和头衔Span缓存渐变，坐标、宽度或颜色变化才重建，头衔RectF复用；消息气泡关闭时在applyBubble开头退出，绑定前原有restoreBoundBubble保留。

未实施群角色持久缓存、昵称合成时序合并、共享数据库观察器、布局观察器和动态撤回暂停规则调整。这些需要完善角色变更失效、跨功能Span/点击目标更新和异步布局恢复证据，不能在功能正常情况下以减少调用为理由直接更改。本次不声称已消除所有聊天热点。

验证：test_chat_safe_optimization.py对实际格式器进行格式/时区/语言/无效格式及并发输出对照；对生产渐变缓存执行1000次同参数复用以及坐标/宽度/颜色失效验证，完整ChatNameDecorationLayout通过Android SDK定向编译。test_chat_time_resolution.py既有3000次绑定反射缓存回归通过。先前艾特提醒、工具栏图标、悬浮透明度、顶部/底部避让、语音转文字及配置备份往返回归通过。未运行Gradle，未完整Compose或APK构建、未实机性能A/B，不承诺具体帧率收益。

按用户本次明确要求，将本轮优化与此前艾特提醒顺序修复、工具栏图标归一、悬浮标题栏/输入框背景透明度及语音转文字一并提交推送。此前文档中的“不提交”是各轮当时状态，本轮授权覆盖该限制。
