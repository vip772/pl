# 动态撤回消息颜色

动态撤回展开项新增“撤回信息颜色”，复用ColorPickerRow单色编辑和恢复默认；默认#808080。另设覆盖强度0–80%，默认35%，0%恢复仅描边。颜色编辑支持RGB/ARGB，最终透明度为颜色alpha×覆盖强度。保存时校验，非法/空颜色回退灰色。

在既有消息内容定位所返回的View.overlay中，先绘制半透明圆角颜色层，再绘制渐变动态描边。覆盖层不创建截图、不更改文字/图片本体、不加点击View，因此适用于既有入口识别的文本、图片、视频封面、语音、卡片、静态及动态表情；表情仍使用微信原有动画。图片原色会透出，不是黑白灰度滤镜。描边颜色独立。

颜色参数在绑定/布局或偏好刷新时读取，绘制使用复用的Paint/RectF，每帧只多一次圆角填充。颜色层与描边同生命周期，绑定复用、关闭开关、detach/dispose清理。没有新增图片解码/文件读写/消息类型扫描。未修改撤回记录隔离、网络诊断、父级或QQ点歌。

验证：tint_run.py编译生产颜色规则，用JVM桩检查默认、错误输入、RGB/ARGB、强度边界与透明效果，并检查覆盖先于描边、偏好刷新和清理接线；原动态角标/撤回生命周期回归通过。未构建APK，未完整编译Compose页面及动态撤回Android运行时。

实机：分别撤回文本、图片、视频、语音、链接/小程序卡片、静态表情、动态表情；确认内容区域完整覆盖，动画继续，点击打开/播放正常。切换颜色和强度保存、设置0%、关闭动态撤回、快速滚动和退出重进，确认普通消息不染色、旧覆盖移除。特殊Holder或独立Surface渲染仍需实机确认，不宣称每一种卡片/表情已验证支持。若失败，提供类型、截图及运行/LSPosed日志，按证据处理。
独立开关：动态撤回下的“撤回信息颜色”默认开启；关闭时隐藏颜色编辑与强度设置，保存后颜色层透明且跳过填充，描边继续。关闭不清除保存的颜色/强度，重新开启沿用设置。偏好前缀使当前已绑定行刷新。
