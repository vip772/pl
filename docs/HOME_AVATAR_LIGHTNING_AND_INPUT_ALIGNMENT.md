# 输入框描边对齐与头像闪电特效

基线：742bdf4。输入：两张实机截图、Hchat-runtime-20261015-155044.log、742bdf4 mapping 压缩包（先检查内部路径并解压至临时目录，内含 mapping.txt）。

## 输入框

原描边作为 EditText 的 GradientDrawable 背景，始终覆盖完整输入控件高度，截图中高于旁边表情图标。现有微信 8.0.78 逆向文件 `/tmp/pl-chat-footer.java` 的 ChatFooter.B0() 确认表情按钮 ID 为 2131366051，对应 APK public.xml 的 id/bqr（0x7f0a10a3）。不新增宿主 Hook。

复用已有表情图标线宽采样，同时缓存可见像素的顶部与底部。ChatInputOutline 在绘制时转换按钮与输入框窗口坐标，使描边外沿对齐表情图标实际顶部、底部；保留输入框布局、文字区域、点击区域和已确认的图标线宽。图标换图或主题变化后重新绑定，位置变化不需要重新采样。采样失败保留原输入框边界。

## 头像光环

原效果仅有低透明整圈轮廓和约38%的移动亮弧，且标题内容没有为边框预留空间。改为清晰完整的渐变轮廓并保留移动亮弧；标题头像昵称四周增加留白，右侧单独留足空间。渐变与柔光按描边宽度内缩，避免贴边裁切。

新增描边宽度滑块：0.5–4.0 dp，默认1.4 dp；只在头像光环开启时显示，已有设置不覆盖。

## 闪电特效

基础设置中在头像特效下增加“闪电特效”，独立开关，默认关闭。开启闪电关闭头像光环；开启头像光环关闭闪电。运行时即使两者存储为true也优先闪电，只绘制一种效果。

闭合电弧持续包围头像昵称，以确定性噪声生成锯齿位移、随机分叉、渐变辉光和白色细亮芯，不绘制原平滑光环。复用三色编辑和动画周期。路径、采样数组复用，按闪电刷新节奏重建，不逐帧创建位图。保持原首页/切标签/聊天/后台生命周期停止策略。
