# 资料页显示设置迁移

## 设置位置与交互

- 删除“群组 → 进入时间/邀请人”入口、专用 SettingsProvider、注册代码、独立页面和页面路由。
- “显示进群时间”和“显示邀请人”统一放入“界面 → 资料页显示 → 群成员资料页”。
- 两项各自拥有独立开关；只有开启对应开关时，才在同一卡片下方显示三色渐变颜色编辑器，支持起始色、中间色和结束色。
- 关闭开关保留已保存颜色，重新开启继续使用；颜色重置只清理对应颜色键，不影响另一项或开关。
- 原有“显示微信 ID”“显示添加时间”交互保持原样。
- 搜索关键词和启用状态聚合统一归入“资料页显示”。

## 实现与配置

设置页面独立为 `ProfileIdMiuixPage.kt`，两个群成员设置复用文件内私有组件，各自读取和写入自己的配置库。原有配置库名称和开关、颜色键保持不变，已有配置和备份无需迁移或复制。

群成员颜色规范化支持最多三色；资料页公共头部绘制支持三色等距渐变，同时继续支持已有单色和双色输入。原有 Provider 与数据查询链路保持不变，不新增 Hook、线程、监听或缓存。

历史资源生命周期审计 JSON 中的旧入口引用是当时的源码证据，保留原样；生产源码中的旧入口和页面已删除。
