# 多行输入描边自适应

基线0c85712。用户截图显示长文本已扩展为多行，边框仍限制在底部表情按钮高度。输入为170125运行日志和0c85712 mapping压缩包（检查后解压，内部mapping.txt）。

原因：ChatInputOutline每次绘制都用表情图标上下像素覆盖输入框边界，没有区分单行、多行。修复仅修改本地Drawable：每次绘制读取TextView当前排版行数；单行继续按表情图标对齐，多行使用输入框完整背景边界，跟随微信原生测量增高。删减至单行后恢复紧凑描边，达到原生最大输入高度时维持包围可滚动文字区域。保持线宽、圆角、透明、微信原生输入布局及头像特效不变，没有新增宿主Hook。

检查：git diff --check、现有background_beauty独立JVM回归。后者覆盖背景与手势，不覆盖TextView实际排版。未运行Gradle或本地APK构建；待实机检查单行→自动换行→长文本滚动→删回单行，以及手动换行和输入法切换。
