# 自动缓存、侧边栏与悬浮底栏背景透明度

## 悬浮底栏

背景不透明度范围 0–100%，默认 100%。背景胶囊、液态玻璃、阴影和背景高光单独绘制在图标下方；透明度只作用于这一背景层。图标、标签、红点及未读数字保持原有不透明度。选中项的半透明背景圈、折射和阴影同样跟随背景不透明度，图标内部颜色不受影响。配置仍为 `Hchat_custom_bottom_bar_config/custom_bottom_bar_opacity`，兼容上一版已保存数值。

## 首页侧边栏

“美化”和“新功能”共用原设置页，增加“昵称头像”独立开关 `Hchat_home_side_panel/show_profile`，默认开启。关闭时隐藏模块自定义标题头，恢复微信原生标题及由微信维护的未读数；从微信主界面左边缘右划打开侧边栏，昵称头像点击入口不变。标题特效改为绘制在原生标题前景，按 TextView 实际文本行宽高自适应计算边界，保持原特效配置。无论是否显示头像昵称，均继续隐藏 TaskBar 内滚动标题整行（微信未读标题、搜索和加号），只保留固定标题栏。重新开启后恢复头像昵称和点击面板行为。关闭侧边栏、切换页面或销毁时恢复原生标题前景，不修改微信原生长按监听。

## 自动缓存

独立总开关默认关闭，沿用 `Hchat_auto_cache_config/enable`；增强、新功能及搜索入口保留。私聊和群聊统一按所选缓存类型处理。处理图片、聊天视频和 AppMsg 类型 6 的附件文档，不把网页链接、小程序等卡片当作文件。

本版删除上一版下载到 `Hchat/AutoCache` 的独立副本逻辑，改成微信内部原生下载：

- 图片：按真实接收消息的服务端 ID 查询微信 ImgInfo2，取得图片本地 ID 和高清父图标记，调用原生 NetSceneGetMsgImg；有原图记录时使用高清模式。由微信写入其图片文件并更新下载状态。
- 视频：使用消息 imgPath 查询原生 VideoInfo，调用 VideoLogic 离线完整接收入口，由微信调度下载并写回状态。
- 任意扩展名的文件文档：通过 AppMsgLogic 的 initDownloadAttach 初始化缺失的附件记录和微信原生路径，再构造 NetSceneDownloadAppAttach，提交微信网络队列。已有记录优先复用；下载完成状态由微信维护，不手动伪造成功。
- 未上传完成、元数据未写齐、网络未就绪时每五秒补查最新消息，最长一小时；已提交任务每分钟检查重试条件，完成后退出队列。观察来源仅使用统一 message.observe，不另订阅重复的新消息来源。
- 当前登录账号未就绪时不提交；切换账号、关闭开关和销毁功能会停止排队任务。微信内部已提交的任务可能继续执行。
- 下载成功后直接从原聊天消息打开。不会继续产生新的模块独立缓存副本；上一版已保存的副本保留。

需要微信进程运行、网络可用和足够存储空间。及时成功下载可避免未下载附件随后失效，但不能恢复已过期内容，也不能保证断网、服务器拒绝或本地文件被清理时仍可打开。
