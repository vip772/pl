# 聊天工具栏图标尺寸

本次处理相册、系统拍摄（复用相册素材）、拍摄、语音通话、位置及红包的图案尺寸不一致。原所有ImageView均为22dp，但宿主素材透明边距可能不同。现仅对这些入口的素材在现有面板快照阶段做96×96有界光栅化，检测有效alpha边界并去除透明外边，按原长宽比例居中显示于22dp区域。后排素材不处理，点击和长按分发、按钮间距及文字模式保留。

归一化结果按宿主Drawable.ConstantState弱键缓存，没有新增滚动监听、定时任务或每帧扫描。每个未命中素材最多扫描9216个像素；处理失败回退原素材。缓存可能在GC或素材状态变化后重新生成，不宣称只执行一次。小尺寸光栅化可能改变极细边缘，需要新包核对不同密度、主题和实际视觉大小；目前没有用户截图或宿主像素样本，透明边距是源码支持的修正方向，实际效果尚未实机确认。

生产辅助类通过Android SDK定向编译，边界算法覆盖透明边距、满幅、非正方形、全透明及低alpha噪点。未运行Gradle、未构建APK。本轮不提交、不推送，保留已有艾特提醒修改。
