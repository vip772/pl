# 悬浮输入栏发送按钮动画收尾

微信8.0.78逆向依据：smali_classes3/com/tencent/mm/pluginsdk/ui/chat/ChatFooter.smali的A()/B()分别使用e0/f0与g0/h0执行150ms隐藏/显示动画。e0/g0每次更新按(width-d7)/(c7-d7)设置发送按钮n的alpha；宽度相同可能产生NaN，取消或交替动画也可能留下非最终透明度。f0/h0结束及取消路径主要处理visibility、宽度与附件按钮，未统一恢复alpha。这是已确认的源码风险，尚无故障现场状态采样证明它是所有偶发消失的唯一原因。

修复仅安装在版本8.0.78、原生已核对的f0/h0 onAnimationStart/End/Cancel。字段n、l4、回调owner e与参数类型在安装时校验；反射成员由KavaReflector一次解析并闭包复用，不在运行时扫描字段。只对已被悬浮输入栏接管的footer生效。

开始记录当前动画身份；结束/取消移除身份并合并下一帧单次收尾。若还有新动画活跃则跳过；执行时重新读取最新原生canSend l4，而不使用结束回调的历史状态。只有按钮和父层可见、仍可发送时将非1透明度恢复为1，包含NaN。按钮GONE、语音父层隐藏、关闭功能或退出页面均不强行恢复。不会修改按钮visibility、width、文字、点击逻辑，也不发送消息。恢复footer时移除待执行任务及动画状态。

开销：只在发送按钮动画事件触发，最多一个待执行Runnable；无周期任务、树扫描、消息扫描、滚动监听或新增onLayout/OnPreDraw检查。前两轮顶部避让缓存真实滚动容器，底部补偿使用实际重叠，两者padding相同时不写布局。既有输入区样式的preDraw维护仍存在，本次未增加其工作量；未以静态测试承诺零性能影响。

验证：生产SendButtonSettlement确定性调度测试覆盖活动动画、新动画竞态、合并、canSend变化、隐藏父层/按钮、NaN、退出清理和空闲无任务；顶部/底部padding、面板状态/高度、共享背景手势与音乐Canvas SDK编译回归通过。未运行Gradle、未构建APK；没有实机复现/性能采样，偶发缺失改善和真实聊天流畅度仍需新包验收。当前仅有8.0.78逆向依据，未扩展到未验证版本。
