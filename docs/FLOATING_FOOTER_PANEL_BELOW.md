# 悬浮输入框与表情、加号面板联动

表情和加号面板在输入框下方展开，输入列在上，ChatFooterBottom 在下，通过 RelativeLayout.BELOW 锚定到输入列。输入框随面板展开上移并贴住其顶部，收起后恢复。

## 面板高度：旧版基础增加50dp

按用户要求，撤销 cffd588 的原生高度策略，恢复37b997b中的压缩算法，然后在旧算法的最终结果上增加50dp：

`新高度 = max(min(首次原生高度, 265dp, 宿主高度×30%), 180dp) + 50dp`

增加发生在旧版上下限计算之后；原本265dp的结果变为315dp，原本180dp的结果变为230dp，不是对原生高度直接增加50dp。表情和加号使用同一规则；原先与首次原生高度相同的子面板同步调整。沿用旧版首次高度缓存，避免每轮刷新重复叠加50dp；关闭、脱离及销毁时恢复保存的高度。

整体负topMargin及消息列表避让仍按输入高度＋可见面板高度＋底部间隔计算，padding基于原始值计算，不累加、不显式滚动消息。保留当前面板可见性、点击入口、键盘状态处理及输入列规则回滚。未新增微信内部类、字段或Hook签名，沿用既有微信8.0.78入口，未扩大跨版本验证。

验证：Android36 SDK＋DexKit定向编译（外围依赖用桩）；提取生产高度算法模型覆盖不同密度、原生高度、宿主高度及100次重复调用，确认新高度始终等于旧结果加50dp，子面板同步、不累加；原有面板锚定、收起、多行输入、测量回退和列表padding回归保留。模型不代表实机动画、触摸和高度验收。未运行Gradle、未构建APK、未操作微信。

安装新包并重启微信后才生效。实机可检查表情与加号面板高度、键盘互切、分页触摸和收起；当前用户已要求跳过验收，不视为已通过。
