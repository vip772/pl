# 首页昵称头像圆形裁剪与外侧2dp轨道

## 范围

基线dev / 2f1226b0b0b32f17f6655afc57aefb76d08c43aa，仅修改HomeSidePanelRuntime与AvatarHeaderEffect，未改群聊分析、收藏消息时间、全局头像或侧栏其他卡片。

首页昵称头像使用BACKGROUND轮廓裁剪，但原圆形Drawable设置在图片层而非背景层；加载真实位图后没有相应圆形背景轮廓。本次将灰色圆形占位改为背景，保留CENTER_CROP与clipToOutline，38dp正方形布局因此按圆形轮廓裁剪。该功能源码没有独立头像形状配置，无配置迁移或覆盖其他头像功能设置。

特效显式接收实际ImageView，通过父容器坐标换算取得头像边界，向四边扩展2dp作为圆形基准轨道，替代原按容器宽度推算的约3dp间距。2dp指头像边缘至轨道中心线；闪电描边、辉光有自身宽度，并非全部可见像素严格相隔2dp。头像闪电随机偏移和分叉改为朝圆外，文字特效保留原路径、抖动与分叉逻辑。现有侧栏个人卡片未传入ImageView，保持原状。

不新增线程、轮询、布局监听或位图副本；复用原路径和坐标矩形，内容边界变化时重建路径。保留已有冷启动headerReady可见性门控、动态容器尺寸与38dp头像居中，未变更挂载时序。
