## 实现

- 报告页顶部采样入口、核心人数/消息/历史指标、总结区采样/设置入口、折叠图标及消息菜单“分析”采用 Canvas/Path 线条绘制，不依赖字符字体或 emoji。

- 无新增后台线程、网络请求、轮询或布局监听。绘制器复用Paint/Path，不使用图标位图缓存。
