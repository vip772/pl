# 动态角标滚动生命周期修正

基线：97ffa08，代码内容与 c5c1492 一致。

## 源码确认的缺口
- 原绑定扫描只接纳可见且有尺寸的角标；数字/圆点切换时另一控件可能被漏管或移除。单帧重试无法覆盖较晚的可见性变化。
- 已附着但尚不可见的行原先等待附着事件，该事件不一定再次发生。
- 动画下一帧原先在 draw 中调度，刷新与绘制入口相互依赖。

## 修改
- 对已验证的数字 ID 2131389131、圆点 ID 2131363591，绑定时同时管理，绘制时继续检查可见性与 bounds，绝不强制显示微信原控件。其它版本保留原判据回退。
- 已附着行不再因 isShown=false 而等待新的附着事件。
- 监听角标本身的附着/脱离，重新附着时恢复刷新。
- 使用 View.postOnAnimation 的自驱动帧回调；停止时移除回调。
- 状态日志每个 Drawable 最多每两秒一条，不受原前40次定位日志限制；不记录会话名称或消息文本。

## 保留
- c5 的宿主、弱引用映射、preDraw updateBounds、外圈几何、宽度/颜色设置均不变。
- 不使用22fa280的每帧overlay.add或强引用映射。

## 验证边界
仅静态检查，未本地Gradle构建、未实际运行微信测试。上述缺口可由源码确认，但不能据此声称已证明全部偶发现象的根因或彻底修复。
