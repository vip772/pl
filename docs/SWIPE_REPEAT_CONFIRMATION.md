# 右划复读发送确认

基准：dev / 56bcd7a。

右划达到阈值并松手后，显示“复读消息”确认框，正文为“确定复读这条消息吗？”，按钮为“取消”和“确定”。仅确定回调调用既有复读发送链路；取消、返回、点击外部关闭及消息行脱离窗口均不发送。左划引用和长按菜单复读保持原有行为。

确认框固定触发时的目标消息及会话，发送前再次检查会话、功能开关、资源所有者和宿主页面是否仍有效。一次只持有一个确认框，确定回调一次消费，防止重复发送。消息行脱离窗口时关闭弹窗；弹窗关闭移除监听及引用，功能销毁时在主线程关闭弹窗。弹窗显示失败记录错误并取消发送。

验证入口：scripts/check_swipe_repeat_sdk.py。使用 Android 36 SDK、当前滑动手势全包及相关核心源码，依赖已有项目 ABI 和 UI 注册夹具，不运行 Gradle。验证：滑动手势全包及当前核心源码 SDK 定向编译 PASS（/tmp/swipe-repeat-sdk-final.log）；源码接线静态检查 PASS（/tmp/swipe-confirm-contract.log），涵盖仅确定回调发送、取消无动作、一次消费及会话/生命周期保护。静态检查不等于弹窗实机测试。
