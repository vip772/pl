# 首页音乐样式二

首页样式二改为横向封面、歌曲名/歌手、上一曲/播放暂停/下一曲；底部白色进度轨道显示已播与总时长，实际播放位置处绘制橙色流星头和渐隐尾。信息下方电弧使用现有真实 FFT 频谱振幅；无权限/无频谱时不伪造节拍。二级播放器维持原布局，样式1/3维持原入口。

日历普通卡片内容高度由上下10dp padding、40dp标题行与90dp日期行构成150dp；音乐普通卡片105dp，比初版增加5dp（比日历少45dp）。双列日历标题两行共58dp，对应音乐123dp；双列布局不强制将样式二音乐拉伸到同排卡片等高。卡片宽度沿用首页布局，内部元素按宽高定位。

现有自定义头像、恢复歌曲封面和music_alpha透明度不迁移。样式二首页封面采用既有12秒一圈逻辑，暂停状态通知立即归零，下一次绘制不保留倾斜角。卡片不可见、失焦或离开窗口时停止帧调度，可见播放期间沿用约30fps上限。背景导入/解码在工作线程，绘制与动画路径不查文件；流星画笔/渐变及电弧Path复用。

样式二设置新增选择/更换、清除背景。系统图片选择器通过SidePanelImagePicker单次结果处理，图片限定32MB，采样压缩后写入resources/home_music/style2_background.jpg；缓存和导入暂存不作为用户资源。复用CalendarBackgroundDrawable及PhotoTransformController：背景空白处长按后拖动、双指缩放，松手或退出保存。进度与控制按钮不进入背景编辑，普通短按保持打开播放器行为。只有背景跟随变换，封面、文本、控件不移动。

图片revision保存在Hchat_home_extension_config，变换保存在Hchat_home_photo_transform的music_style2_<revision>命名空间，图片更换后隔离旧参数。统一备份恢复图片、透明度、revision和变换，避免文件时间戳变化导致参数丢失；运行缓存不持久化。

验证：完整生产Canvas视图、图片导入和共享手势/Drawable Android SDK定向编译（播放器/存储宿主依赖使用桩）；共享手势确定性拖动/缩放/保存恢复回归；生产归档图片、透明度、revision与偏移往返通过。未运行Gradle、未构建APK，真实视觉、长按分发、播放按钮、音频权限和首页滚动性能仍需新包验收。
## 实机反馈调整

时间与进度轨道处于同一行、分列轨道外侧；橙色已播放段与白色未播段，流星保留渐隐拖尾但不绘制圆形进度头。移除样式二首页背景上额外的0x33131717内层暗色遮罩；透明度仍只控制背景。歌曲/歌手基线间距增加9个归一化纵向单位；三个控制按钮及其点击范围整体右移5dp。频谱电弧使用蓝、紫、金渐变，复用Path与渐变缓存。

专辑普通白边替换为红紫蓝渐变环，核心线宽3dp，核心内缘距封面1dp。GradientOrbitStroke从AvatarHeaderEffect既有绘制路径提取，保留全周渐变、38%拖尾和柔光层；原头像效果调用共享实现、参数不变。音乐卡片使用自身可见播放帧调度，未新增独立动画计时器；暂停回正并停止环的持续刷新。

标题栏反馈精查：上一提交的顶部补偿方法未接入apply，且精确类名查找遗漏ScrollControlRecyclerView。8.0.78 ss.xml中bm6为MMChattingListView；smali_classes11/com/tencent/mm/ui/chatting/view/MMChattingListView.smali的m(Context)将布局0x7f0e043b实例化为ScrollControlRecyclerView，设置ChattingLinearLayoutManager并存入T，之后给实际滚动控件设置底部6dp padding与clipToPadding(false)。本次补齐实际apply调用并优先命中内层真实滚动控件，保留底部padding。检查仅走原有布局稳定分发，缓存命中不再查树；没有滚动监听或消息逐条扫描。范围依据现有8.0.78材料，未声称覆盖其它版本。

新增调用链断言，避免仅测试孤立的inset方法；补测具体滚动子类匹配。SDK编译及手势/顶部inset回归通过。尚未构建APK，首次消息实际位置、真实字体布局与首页动效仍需实机验收。
