# 内置表情艾特

入口位于“增强功能”和“新功能”，共用 `emoji_at` Provider 与 Miuix 设置页。配置为 `Hchat_emoji_at_config/enable`，默认关闭，只在微信主进程运行，不依赖脚本插件系统。原表情艾特脚本应停用，避免重复拦截。

## 行为

群聊自定义表情发送入口弹出“普通发送 / 艾特发送”；取消不发送。普通发送恢复原调用；艾特发送在后台读取成员 ID，排除当前账号、系统账号、重复与非法值，最多499人，不逐个读取昵称，不额外发送文本。账号或名单不可用时不发送，并提示重试或选择普通发送。

单次恢复调用通过 ThreadLocal 隔离，入库仅处理同群、自己发出的 type 47 消息。入库后的真实消息 ID 与群 ID 组合关联上行请求；请求项在序列化前重新写入名单。待上行名单及请求项关联上限128项，120秒过期，周期清理；关闭与销毁时卸载Hook、清空关联并使旧选择回调失效。

## 定位与保护

脚本提供的字符串锚点和混淆字段只是迁移依据，未视为跨版本逆向结论。定位走共享 DexKit、DexMethodCache 当前 runtime key 和 DexInstallScheduler 有限补装。候选不唯一时不挑选任意结果。检查消息方法/字段、请求字段路径、List泛型项类型、MsgSource字符串字段及序列化签名；缺泛型元数据或结构不符时不安装发送拦截，保持原发送。

下游Hook先安装，发送选择最后安装；部分安装失败时回滚。名单写入失败记录微信版本与阶段。普通发送或界面不满足条件时保持原调用。依赖异步入库的版本可能无法继承当前调用作用域，因而表情会发送但不附带艾特；本实现不会另发补偿消息。

## 验证与限制

四个原生 Kotlin 文件已通过 Android SDK + 依赖桩的定向类型编译，验证成员过滤/去重/上限、XML其他节点保留、未知格式拒绝、同消息ID跨群隔离、单次消费、超时、容量和清空。

未执行 Gradle 或完整 Compose 编译，未完成微信内双端发送测试。未取得默认验证集合 8.0.49、8.0.58、8.0.66、8.0.68、8.0.72、8.0.74、8.0.76、8.0.77 APK，也无可调用的 DexClub/工具搜索接口，因此没有完成这些版本的横向逆向验证。结构检查通过只表明候选类型符合脚本假设，不能证明字段p对应上行协议MsgSource，也不能证明服务端接受或收件方实际收到提醒；499是本地名单上限。存在多个并行业务入口的版本仍需APK证据确认覆盖情况。
