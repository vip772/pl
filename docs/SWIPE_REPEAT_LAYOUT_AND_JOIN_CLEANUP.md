# 右划复读布局与进群时间诊断清理

基线：`583ade180cb40e0a19e07956820d1f00682fc155`，工作分支 `dev`。

## 文案完整显示

旧实现复用 AlertDialog 的标题、滚动消息和按钮面板，隐藏标题后固定面板尺寸，再对原始模式设置字号并通过 translationY 上移消息。消息仍在原生滚动容器的测量约束内，移动不能扩大文本可用高度，可能仅显示末尾文字；温柔模式又跳过此定位，造成两种文案不一致。

两种文案现在共用 ConfirmationCard：消息按实际宽度和字体测量，正文主体最小高度 104dp，较长文案撑高主体；消息在主体中水平、垂直居中。下方按钮扩展单独占用 72dp，不参与正文居中。保留粉色异形轮廓、橙色取消按钮、绿色确认按钮和温柔文案的微信表情转换。取消、确认、会话冻结、单次发送保护和消息行移除时关闭的行为保持。

## 指纹确认

64dp 圆形按钮使用蓝色渐变、3dp 橙色外圈及白色矢量指纹纹路，无图片缓存和动画。以当前聊天工具栏实际屏幕坐标定位，按钮底边距工具栏顶边 100dp，水平居中；工具栏关闭时以原生 ChatFooter 输入区域作为参照，均不可用时以窗口底边参照。极小可用空间时限制到窗口顶部。点击空白取消，点击指纹执行已有确认动作。

## 诊断清理

删除 JoinTimeNativeDiagnostics 及其 13 处原生诊断 Hook、嵌套事件跟踪、反射字段缓存、原生写入哈希回读队列、显示诊断状态、消息结构采样、历史消息类型 GROUP BY 统计和只为输出统计而存在的字段。删除诊断专用测试并更新相关检查夹具。

保留进群时间本地/原生查询、服务器补查、绑定持久化、成员变更监听、账号隔离、32群缓存与任务上限、未完整结果重试，以及必要异常日志。原生 roomdata 读取完整性使用 RoomDataReadStatus 继续传递，避免清除诊断时把读取失败视为成功空结果。清理后不再通过临时原生写入探针额外回读刷新，正常显示仍由查询完成和成员事件刷新。
